GET /api/v1/auth/callback 테스트

state 는 버튼에 따라 github / google 로 전달된다 (AuthService 가 provider 키로 사용).

1. 프록시로 호출 — 302 / Set-Cookie 원본 확인

Node 서버가 대신 호출하고 redirect 를 따라가지 않는다. 상태코드(302), Location, Set-Cookie 를 그대로 볼 수 있다. 

아직 호출 안 함

2. 브라우저에서 직접 호출 — 실제 리다이렉트/쿠키 동작 확인

브라우저가 302 를 따라가 http://localhost:3000 으로 돌아온다. 쿠키는 DevTools > Application > Cookies 에서 확인. 현재 서버 코드는 쿠키 path 가 /callback 이라 /api/v1/auth/* 요청에는 자동으로 실려가지 않는다.
